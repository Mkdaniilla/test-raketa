# 🚀 Ракета «Союз-М» — Pixel Art Game

Мини-игра на **Python** и **Pygame** в стиле ретро-пиксель-арт с ракетой «Союз-М».

---

## 🎮 Описание
* Детализированная 2D-модель ракеты в стиле «Союз» с красным носовым обтекателем, боковыми ускорителями и надписью «СОЮЗ М» на борту.
* Анимированный старт и реалистичное пиксельное пламя при взлёте.
* Эффектное появление надписи **СОЮЗ-М** по центру экрана после выхода ракеты на орбиту.

---

## 🕹️ Управление
* **Пробел (Space)** — запуск ракеты в космос.
* **R** — перезапуск и возврат ракеты на стартовую площадку.

---
