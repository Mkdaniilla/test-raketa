# 🚀 Ракета «Союз-М» — Посадка на Луну с Космонавтом (Pixel Art Game)

Увлекательная 2D мини-игра на **Python** и **Pygame** в стиле ретро-пиксель-арт с ракетой «Союз-М», анимацией космонавта и полноценной миссией посадки на Луну.

---

## 🎮 Игровой процесс и анимации

1. **🧑‍🚀 Подготовка и посадка в ракету (Земля):**
   * Пиксельный космонавт в белом скафандре с ранцем жизнеобеспечения стоит на стартовой площадке.
   * При нажатии **Пробела** космонавт идёт к ракете, поворачивается, **машет рукой 👋** и садится через входной люк внутрь.
   * Люк закрывается, запускается обратный отсчёт (3... 2... 1... ПУСК!), из двигателей клубится предстартовый дым.

2. **🌍 Старт и космический полёт:**
   * Ракета «Союз-М» с рёвом и двухслойным пламенем стартует вертикально вверх в открытый космос.

3. **🌕 Посадка на Луну:**
   * Космический пейзаж со звёздами, кратерами и далёкой планетой Земля.
   * Ракета снижается на тормозных двигателях, выпускает посадочные опоры (лапы) и совершает мягкую посадку в клубах лунной пыли.

4. **🚩 Выход на поверхность Луны (EVA):**
   * Люк ракеты открывается, космонавт выходит на лунный грунт, водружает знамя и победно приветствует игрока.
   * По центру экрана выводятся праздничные титры **«СОЮЗ-М»** и **«ПОСАДКА НА ЛУНУ УСПЕШНА!»**.

---

## 🕹️ Управление

* **Пробел (`Space`)** — посадка космонавта в ракету, предстартовый отсчёт и запуск.
* **`R`** — перезапуск всей миссии с Земли.

## 📦 Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/Mkdaniilla/test-raketa.git
cd test-raketa
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Запуск игры
```bash
python main.py
```
