# 🚀 Ракета «Союз-М» — Посадка на Луну (Pixel Art Game)

Увлекательная 2D мини-игра на **Python** и **Pygame** в стиле ретро-пиксель-арт с ракетой «Союз-М» и полноценной миссией посадки на Луну.

---

## 🎮 Игровой процесс и особенности

1. **🌍 Старт с Земли:**
   * Детализированная модель ракеты «Союз-М» с красным носовым обтекателем, боковыми ускорителями, иллюминатором и надписью «СОЮЗ М» на борту.
   * Стартовая площадка в окружении кирпичных конструкций.
   * Двухслойное анимированное пламя при взлёте.

2. **🌕 Космический переход и посадка на Луну:**
   * Динамическое переключение сцены с Земли в открытый космос.
   * Проработанный лунный пейзаж: кратеры, посадочная площадка со световыми маячками и далёкая планета Земля на фоне звёздного неба.
   * Реалистичное торможение ракеты на подлёте к поверхности.
   * Автоматический выпуск посадочных опор (лап).
   * Клубы лунной пыли в момент касания грунта.

3. **🚩 Триумф миссии:**
   * Установка флага на лунном грунте рядом с ракетой.
   * Красивые золотые титры **«СОЮЗ-М»** и **«ПОСАДКА НА ЛУНУ УСПЕШНА!»**.

---

## 🕹️ Управление

* **Пробел (`Space`)** — запуск ракеты в космос и начало лунной миссии.
* **`R`** — перезапуск миссии и возвращение ракеты на стартовую позицию на Земле.

## 📦 Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/Mkdaniilla/test-raketa.git
cd test-raketa
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Запуск игры
```bash
python main.py
```
