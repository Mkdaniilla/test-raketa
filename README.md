# 🚀 Ракета «Союз-М» — Космодром и Посадка на Луну (Pixel Art Game)

Красочная 2D мини-игра на **Python** и **Pygame** в стиле ретро-пиксель-арт с детально воссозданным космодромом на Земле, анимированным космонавтом и миссией высадки на Луну.

---

## 🎮 Особенности и локации

1. **🏭 Атмосферный космодром (Земля):**
   * Градиентное сумеречное ночное небо со звёздами и силуэтами гор/леса на горизонте.
   * Стартовая вышка обслуживания со стальными красными фермами и мигающим красным маяком.
   * Переходный мостик с перилами, ведущий к входному люку ракеты.
   * Мощные прожекторы стартового комплекса, освещающие ракету лучами света.
   * Бетонный стартовый стол с черно-жёлтой разметкой безопасности и газоотводным лотком.
   * Радарный пункт управления с вращающейся антенной.
   * Выделение клубов кислородного пара перед стартом.

2. **🧑‍🚀 Космонавт и предстартовый процесс:**
   * Космонавт в детальном скафандре с приборной панелью, ранцем и бликом на шлеме.
   * При нажатии **Пробела** космонавт идёт по стартовой платформе, машет рукой игроку 👋 и заходит в ракету.
   * Люк закрывается, включается обратный отсчёт (3... 2... 1... ПУСК!), из двигателей клубится предстартовый дым.

3. **🌍 Полёт и 🌕 посадка на Луну:**
   * Взлёт на двухслойном пламени и переход в космическое пространство.
   * Лунный пейзаж с кратерами, огнями посадочной площадки и далёкой планетой Земля в небе.
   * Мягкое торможение, автоматический выпуск посадочных опор (лап) и клубы лунной пыли.
   * Выход космонавта на поверхность Луны, водружение флага и золотые победные титры **«СОЮЗ-М»**!

---

## 🕹️ Управление

* **Пробел (`Space`)** — посадка космонавта в ракету, предстартовый отсчёт и запуск.
* **`R`** — перезапуск всей миссии с космодрома на Земле.

## 📦 Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/Mkdaniilla/test-raketa.git
cd test-raketa
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Запуск игры
```bash
python main.py
```
